# 第一圣殿 · 所罗门圣殿 3D 复原

依据和合本经文复原所罗门在摩利亚山上为耶和华所建的殿，给教会会友查经学习用。可以从空中俯瞰圣殿山，也可以走进殿里。鼠标停在任何东西上会显示名称和经文；单击（手机上轻点）会打开它的全部经文依据。

## 怎么打开

- **网上**（手机、平板、电脑都能开）：
  - GitHub Pages：https://zhouqingni.github.io/first-temple-3d/
  - Cloudflare：https://first-temple-3d.zhouqingni.workers.dev
- **离线**：下载 `网页/index.html`（本机构建后也在 `dist/第一圣殿.html`），双击用 Chrome、Edge 或 Safari 打开。不需要联网；没有网络时，字体会改用系统自带的宋体。
- 第一次打开会显示操作说明。右上角“说明”按钮可以随时再看。

## 怎么看

| 方式 | 电脑 | 手机 / 平板 |
|---|---|---|
| 俯瞰 | 拖动旋转，滚轮缩放，右键拖动平移；双击飞过去 | 单指旋转，双指缩放、平移 |
| 漫步 | W A S D 或方向键行走，按住 Shift 快走，拖动鼠标转头 | 左下角摇杆行走，右侧拖动转头 |
| 导览 | 17 站讲解，可以自动播放，也可以朗读；最后一站接“献殿之日”六个阶段 | 同左 |

**快捷键**：1 俯瞰　2 漫步　3 导览　R 揭顶　D 尺寸　M 平面图　I 索引　Esc 关闭

**右侧开关**：揭顶（看殿内格局）、尺寸标注、地名、平面图（点按可前往）、殿门开关、人物显示。

**设置**：
- 时段：清晨、正午、黄昏、夜晚。
- 场景：平日献祭、献殿之日。
- 廊高：120 肘或 30 肘。
- 柱高：18 肘或 35 肘。
- 一肘的长度：52.5 厘米或 44.5 厘米。
- 画质、朗读。

## 标记的意思

- **明载**：经文写明的。
- **推测**：经文没有记载，参考旁证补全，面板里会写出依据。
- **异读**：经文之间有出入，面板里会把相关经文都列出来。

## 经文依据

所有经文都取自本机的和合本（eBible.org `cmn-cu89s`，公有领域），由脚本逐节提取，不是手打的，测试会检查每一处引用都能找到。共 76 个条目，引用 424 节经文。

主要依据：
- 殿：王上 6 章、代下 3 章。
- 铜器：王上 7:13-51、代下 4 章。
- 宫室：王上 7:1-12、10:16-21。
- 献殿：王上 8 章、代下 5-7 章。
- 约柜、陈设饼桌子、灯台、香坛、幔子：出 25-27、30、37 章。
- 祭司圣衣：出 28、39 章。

## 经文之间的出入（可以在设置里切换）

| 项目 | 经文 | 复原默认 |
|---|---|---|
| 廊高 | 代下 3:4 一百二十肘；列王纪未载 | 120 肘 |
| 柱高 | 王上 7:15、耶 52:21 十八肘；代下 3:15 三十五肘 | 18 肘 |
| 柱顶高 | 王上 7:16 五肘；王下 25:17 三肘 | 5 肘 |
| 铜海容量 | 王上 7:26 二千罢特；代下 4:5 三千罢特 | 仅文字说明 |

## 主要的推测

- 墙厚：底层 6 肘，每层收 1 肘，形成搁旁屋梁木的墙坎（王上 6:6）。旁屋外墙 5 肘（参结 41:5、9）。
- 内院 200×100 肘：圣殿是会幕的两倍，院子也按会幕院子（出 27:18）的两倍计算。
- 殿基高 3 肘（参结 40:49）。内院比大院高（耶 36:10“上院”）。
- 铜坛做坡道而不做台阶（出 20:26）。
- 宫室各座建筑的布局、院门位置、地形，都是推测的。
- 灯台照出 25 章会幕灯台的样式来做。灯原本从晚上点到早晨（出 27:21），复原中为了便于观看一直亮着。
- 至圣所里没有灯（“耶和华曾说他必住在幽暗之处”，王上 8:12），所以复原中比圣所暗得多。

## 人物

- 大祭司穿全套圣衣：
  - 以弗得和胸牌，胸牌上四行十二颗宝石；
  - 蓝袍底边上石榴与金铃铛相间；
  - 冠冕前面系着“归耶和华为圣”的金牌。
- 祭司穿细麻衣，在坛上、盆座旁和圣所里供职；利未人守门、歌唱。
- 百姓男女老少都有：一家人同行，老人拄杖，有人扛着羊羔、头顶果筐、手捧斑鸠。
- 献殿之日：
  - 一百二十个祭司吹号，利未人歌唱；
  - 所罗门在铜台上跪下祷告；
  - 会众站满大院，看见火降下后一齐俯伏。

## 文件夹

| 位置 | 内容 |
|---|---|
| `网页/index.html` | 公开发布的网页（GitHub Pages、Cloudflare 都发布这个），也可下载后离线打开 |
| `dist/` | 本机构建输出（不上传）：离线版、发布到 Claude 的在线版 |
| `src/data/catalog.json` | 全部条目：名称、简述、尺寸、经文引用、明载／推测／异读说明 |
| `src/data/verses.json` | 由脚本从和合本提取的经文（不要手改） |
| `src/core/` | 布局常量、引用解析、碰撞、地形高度函数 |
| `src/world/` | 场景：材质、地形城市、殿、陈设、院落铜器、宫室、人物、特效 |
| `src/ui/` | 界面：控制、拾取、面板、标注、平面图、导览 |
| `脚本/提取经文.py` | 从和合本 USFM 提取条目引用的经文 |
| `文档/` | 设计文档与实施计划 |

## 修改与重新生成

```bash
npm install
```

```bash
npm run extract
```

```bash
npm test
```

```bash
npm run build
```

- 改了 `catalog.json` 的经文引用后，先运行 `npm run extract`，再运行 `npm test`，确认每节经文都找得到。
- 和合本原文默认从 `../圣经人物关系图/数据源/和合本/usfm` 读取。

## 发布与更新

改完代码后：

```bash
npm test && npm run build
```

- **GitHub Pages**：把改动（包括 `网页/index.html`）提交并推送到 `main` 分支，会自动发布。
- **Cloudflare**：运行 `bash 脚本/发布到Cloudflare.sh`（设置在 `wrangler.jsonc`；第一次要先 `npx --yes wrangler@4 login`）。

## 已知的限制

- 人物是简化造型，没有五官。
- 宫室只做了外形，以及黎巴嫩林宫和审判廊的内部。
- 旁屋不能进入，旋螺楼梯只能从门口看到。
- 在较旧的电脑上会自动降低画质和分辨率，也可以在设置里手动选择画质。
