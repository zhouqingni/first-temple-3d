# 第一圣殿 3D 复原 · 实施计划

> 执行方式：本会话内由 Claude 逐项实现（用户已授权"看着怎么好怎么做"）。

**目标**：一个离线单文件网页，可俯瞰、漫步、导览所罗门圣殿及圣殿山，悬停/点按显示和合本经文。
**架构**：数据（条目+经文）与场景分离；场景按区域拆模块，统一以"肘"为单位；碰撞与地形高度是纯函数，可单测。
**技术**：three@0.169.0、esbuild@0.24.0、Node 内置 `node:test`、Python3（提取经文）。
**设计**：`文档/设计.md`

## 全局约束

- 1 单位 = 1 肘；+X 东、-Z 北、+Y 上；殿门朝东，至圣所在西。
- 所有界面文字为简体中文；经文一律取自本机和合本 USFM，不手打。
- 每个可悬停物件都有条目 `id`，条目带 `status`：`明载` / `推测` / `异读`。
- 单文件输出 `dist/第一圣殿.html` 可双击离线打开；在线版 `dist/在线版.html` 去掉 html/head/body 外壳。
- 手机（触屏、窄屏）可用；画质分低/中/高三档。

## 复查重点（最可能出问题的地方）

1. 手机触屏：拖动转视角和点按查看要能分清（移动超过 8px 算拖动）。
2. 漫步时不能穿墙、不能掉出地面；从大院上台阶到内院、再上殿基要顺畅。
3. 条目引用的经文必须都能在和合本里找到（测试会检查）。
4. 切换"廊高 120/30""柱高 18/35"后，碰撞和标注也要跟着变。
5. 低端设备上首屏加载不能卡死：程序生成纹理要控制尺寸，人物数量按画质分档。

## 文件结构

```
package.json / build.mjs
脚本/提取经文.py                 条目里的引用 → src/data/verses.json
src/core/refs.js                解析"王上6:2-3"等引用（纯函数）
src/core/colliders.js           盒体/坡道碰撞、取地面高度（纯函数）
src/core/terrain-fn.js          地形高度函数、地名区域（纯函数）
src/core/layout.js              全部关键坐标与尺寸（唯一来源）
src/data/catalog.json           条目：名称、简述、尺寸、经文、状态、说明
src/data/tour.js                导览各站
src/world/*.js                  材质、地形城市、天空、殿、内部陈设、院落铜器、宫室、人物、特效
src/ui/*.js                     控制（俯瞰/漫步/导览）、拾取、面板、标注、小地图
src/index.html                  界面骨架与样式
test/*.test.mjs                 refs、colliders、terrain、catalog 完整性
```
